# Presentación de avances (planteamiento anterior, archivado)

Material de las presentaciones de avances (semanas 11 y 14). Corresponde al planteamiento anterior, "mortalidad en
carreteras según el nivel de precipitación", y a sus modelos: baseline, Modelo 1 (prevención) y Modelo 2 (triaje).

El 12/11/2026 el proyecto se replanteó como dos problemas de ML (pronóstico de riesgo y triaje de gravedad; ver el
README principal, §1). **Nada de esta carpeta refleja el planteamiento actual.** Se conserva como historia del
proyecto. `figuras.py` usa las columnas y los modelos de la versión anterior, así que ya no se ejecuta contra los datos
actuales.

- `presentacion_avances_v1.pdf`: presentación de avances de 8 diapositivas, que antes estaba en la raíz como `presentation.pdf`.
- `Avances · Mortalidad vial y lluvia.pdf`: primera versión, de 3 diapositivas.
- `presentacion_final.html`, `GUION_FINAL.md` y `BRIEF_CLAUDE_DESIGN.md`: fuente, guion y brief de esas presentaciones.
